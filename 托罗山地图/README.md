## 二、手机 / 触屏怎么用的（以及坐标系约定）

**手机上是能用的**：单指拖动平移、双指捏合缩放、双指按住拖走地图、双击放大，
桌面端同时保留鼠标拖动 + 滚轮缩放。

### 坐标系只有一条约定（改代码前务必看这段）

缩放**不是**用 `transform: scale()` 缩放 SVG 元素，而是**直接改 `viewBox`**。
`<svg>` 上写了 `preserveAspectRatio="none"`（这是刻意的），viewBox 由脚本按屏幕比例设置，
所以 viewBox 正好铺满整个 `#map-wrap`，换算就是一条干净的线性关系：

```
屏幕x = (图x - vb.x) / vb.w * 容器宽        图x = vb.x + 屏幕x / 容器宽 * vb.w
屏幕y = (图y - vb.y) / vb.h * 容器高        图y = vb.y + 屏幕y / 容器高 * vb.h
```

**为什么不用 `transform: scale()` 缩放 SVG 元素**：那会跟 SVG 自己的
`preserveAspectRatio` 叠加，形成两层坐标系——外面的 `scale` 和 SVG 内容自己的基准缩放
不是一个东西，量出来的"图占多少像素"和算出来的对不上，怎么调都会错位。
（这就是这次绕了远路的原因，写下来免得以后再踩。）

改交互时记住：`vb` 是 **getter**（`getVB()`），不是快照。`clampView()` 是就地改属性的，
快照一份的话后面读到的永远是初始值。

### LOD 判据

用 **viewBox 宽占整幅地图的比例**，跟屏幕像素无关，所以手机和桌面看到的细节层级一致：

| viewBox 宽 | LOD | 显示什么 |
|---|---|---|
| ≥ 1200（占 3/4 以上） | `min` | 整县轮廓、县名、山名、大水域 + 9 个关键地名 |
| 480 ~ 1200 | `mid` | 城区轮廓、主要街道、政府/医院/车站/大桥 |
| < 480 | `max` | 全部小店、路名、次干道 |

### 手机端做的适配

- `#map-wrap` 设了 `touch-action: none`，浏览器不会把触摸拿去滚页面
- 图例面板收窄到 ~93px、缩放按钮放大到 42px（手指点得中）
- 详情面板窄屏改成**贴底卡片**（宽屏仍是右上浮动），不会挡住它标出来的那个点
- 转屏 / 改窗口大小会按当前中心重新铺满，不会留一片底色
- **不做"记住上次看到哪儿"**：手机转屏后旧的 scale+translate 必然失效，恢复出的是错位视图

## 三、想再改怎么弄

底图几何是**脚本生成的**，不要手改 HTML 里那一大段 SVG（改完下次生成就覆盖了）。正确流程：

```powershell
# 1) 改 gen_map.py 里的参数（见下表）
# 2) 重新生成 + 嵌进 HTML
python O:\mirror\凌汛素材\_tools\patch_map.py
# 3) 跑交互验收
node O:\mirror\凌汛素材\_tools\verify_map.mjs
```

`patch_map.py` 只替换两个地方，**POI 数据、交互脚本、面板一个字都不碰**：

1. SVG 里 `<rect class="land"/>` 到 `<g id="poi-layer"></g>` 之间 → 换成新生成的底图
2. 样式表里「SVG 元素分层」那一段 → 换成新版路网/注记样式

改之前它会先检查这两个锚点在不在，**找不到就直接中止、不写文件**，不会把 HTML 改坏。

### 常用调节点（都在 `gen_map.py` 顶部）

| 想改什么 | 改哪里 |
|---|---|
| 路网横/竖街道的位置 | `HY`（一道街…五道街的 y）、`VX`（兴山路…黎明湖街的 x）。**注意这几个值是从 POI 反推的**，动了 POI 就会偏出路外 |
| 城区轮廓 | `CITY`（24 个顶点） |
| 路"长歪"的程度 | `wobble_pt()` 里的系数，现在横向 ±11px、纵向 ±9.5px。**调太大会让 POI 偏离街道**，超过 ±20 就要小心 |
| 对外公路走向 | `OUT` 字典（矿安路 / 省道S203 / 城郊路 / 水库路 / 育才路 / 矿山路 / 老省道） |
| 水库形状与大小 | `blob(1352, 508, 200, 128, 31, 20, 0.20)` 这行的中心、半径、粗糙度 |
| 村屯 | `VILLAGES` |
| 池塘 | `PONDS` |
| 田块范围 | `FIELD_BOXES`（田块会自动躲开城区/水域/公路走廊，见 `build_mask()`） |
| 整体随机种子 | `SEED = 20261017`，改一个数整张图的地貌就换一套 |

## 四、怎么验收

```powershell
node O:\mirror\凌汛素材\_tools\verify_map.mjs          # 桌面
node O:\mirror\凌汛素材\_tools\verify_map_mobile.mjs   # 手机（真实触摸事件）
node O:\mirror\凌汛素材\_tools\verify_map_links.mjs    # 两个官网的页脚入口
```

三套共 **112 项，当前全部通过**：

| 脚本 | 项数 | 测什么 |
|---|---|---|
| `verify_map.mjs` | 36 | 底图 7 个图层、**坐标换算误差 ≤10px**、37 个 POI 可点、三级 LOD、图层开关、拖拽 + 捏合 |
| `verify_map_mobile.mjs` | 51 | 手机竖屏 ×2 + 横屏，用 CDP 发**真实触摸事件**：单指拖、双指张开/收拢、抬一根手指不跳图、点 POI、不滚页面、转屏 |
| `verify_map_links.mjs` | 25 | 政府官网（友情链接 + 页脚两处）与学校官网页脚的地图入口，**源目录和发布目录各点一遍**，确认真能打开地图 |

桌面/手机两套用 Chrome DevTools Protocol 驱动无头 Chrome，全程
`Runtime.exceptionThrown` / `console.error` 计数必须为 0。
报告写在 `O:\mirror\_mapcheck\`。

验收截图也在这个目录（`电脑-整幅.png` / `电脑-放大近景.png` / `手机-竖屏起手.png` /
