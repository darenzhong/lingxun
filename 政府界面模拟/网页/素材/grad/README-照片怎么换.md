# 毕业生照片：怎么换

这个文件夹里的 `grad-年份-序号.jpg` 就是「优秀毕业生展示」页面的头像。
**换图不需要改任何代码**——把新图改成同样的文件名丢进来覆盖就行。

## 最省事的换法（推荐）

1. 打开 `O:\mirror\凌汛素材\政府界面模拟\素材\毕业生\`
2. 把新照片（随便什么尺寸，方的最好）拖到这个文件夹里
3. 选中新照片，按 **F2** 重命名，改成你要替换的那个文件名，例如 `grad-2026-1.jpg`
4. 弹窗问"是否替换"→ 是
5. 浏览器里刷新一下官网页面，头像就变了

## 如果想把新照片直接拖进记事本

也可以用「记事本打开 HTML、改一行路径」的办法给某个人单独指定一张图，
但**没必要**——用上面的覆盖法，页面根本不用改。

## 想给某个人单独换一张、又不想动其他图

在官网 HTML 的 `GRADS` 里，给那个人这条末尾加第 4 项写图片路径即可，其余人不受影响：

```js
2026:[["林子昂","北京大学","2026年高考全县理科第一名","../素材/毕业生/我自己的照片.jpg"], ...]
```
